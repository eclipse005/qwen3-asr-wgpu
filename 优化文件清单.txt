💡 使用提示
───────────────────────────────────────────────────────────────

性能最佳实践:
  ✓ 使用批量模式（--batch 8 或更高）
  ✓ 连接电源（避免电池模式限制）
  ✓ 首次运行预热 GPU
  ✓ 使用 Metal 后端（自动）

推荐配置:
  • M1: batch=4-8, 0.6B 模型
  • M1 Pro/Max: batch=8-16, 0.6B/1.7B 模型
  • M2/M3: batch=8-12, 0.6B 模型
  • M2/M3 Pro/Max: batch=16-32, 0.6B/1.7B 模型

常用命令:
  # 验证优化
  ./verify_optimizations.sh
  
  # 构建项目
  cargo build --release
  
  # 转录单文件
  ./target/release/transcribe --model <模型> --wav <音频>
  
  # 批量转录
  ./target/release/transcribe --model <模型> --batch 8 \
    --wav file1.wav file2.wav file3.wav
  
  # 性能测试
  ./benchmark.sh <模型路径> <音频文件...>
  
  # 性能分析
  QWEN3_ENC_PROFILE=1 ./target/release/transcribe \
    --model <模型> --wav <音频> --timings
