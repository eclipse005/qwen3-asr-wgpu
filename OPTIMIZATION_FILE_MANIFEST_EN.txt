💡 Usage Tips
───────────────────────────────────────────────────────────────

Performance Best Practices:
  ✓ Use batch mode (--batch 8 or higher)
  ✓ Connect power (avoid battery mode limitations)
  ✓ First run warms up GPU
  ✓ Use Metal backend (automatic)

Recommended Configuration:
  • M1: batch=4-8, 0.6B model
  • M1 Pro/Max: batch=8-16, 0.6B/1.7B model
  • M2/M3: batch=8-12, 0.6B model
  • M2/M3 Pro/Max: batch=16-32, 0.6B/1.7B model

Common Commands:
  # Verify optimizations
  ./verify_optimizations.sh
  
  # Build project
  cargo build --release
  
  # Transcribe single file
  ./target/release/transcribe --model <model> --wav <audio>
  
  # Batch transcription
  ./target/release/transcribe --model <model> --batch 8 \
    --wav file1.wav file2.wav file3.wav
  
  # Performance testing
  ./benchmark.sh <model_path> <audio_files...>
  
  # Performance profiling
  QWEN3_ENC_PROFILE=1 ./target/release/transcribe \
    --model <model> --wav <audio> --timings
